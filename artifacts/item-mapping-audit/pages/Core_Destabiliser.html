Core Destabiliser

Core Destabiliser is a currency item that can randomly modify a soul core or destroy it.

Mechanics

Using this item can result in the following outcomes:

  • Double the Soul Core
  • Transform the Soul Core into another random Soul Core of the same tier
  • Transform the Soul Core into an ancient soul core
    • Citaqualotl's Thesis
    • Guatelitzi's Thesis
    • Jiquani's Thesis
    • Quipolatl's Thesis
  • Destroy the Soul Core

Item acquisition

Core Destabiliser has restrictions on where or how it can drop.

Can be taken instead of using the crafting bench in a Tier 3 Alchemy Lab room (Grand Phylactory) in Atziri's Temple. Can also drop from Royal Trove in Atziri's Temple after defeating Atziri, the Red Queen.
